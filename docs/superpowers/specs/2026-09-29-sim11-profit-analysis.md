# 심11 미너비니 — 수익을 내려면 무엇이 개선되어야 하나 (2026-09-29 백테스트)

## 결론 먼저

1. **VCP 0.85 기준선의 수익은 2025년과 거래 13건이 다 만든다.** 상위 1%(13건)를 빼면 거래당 +0.48%(일별 t 0.40), 2025년을 빼면 +0.23%(t -0.35)다. 설계 구간(2023-07~2025-06)도 검증 구간도 t 1.7 정도라 판정 기준(t≥2)에 못 미친다.
2. **손실은 -7.5% 손절에서 나온다.** 전체 1396건 가운데 44%인 620건이 손절로 끝나고(평균 -7.82%, 합계 -4849%p), 그중 절반인 310건은 3거래일 안에, 125건은 진입 당일에 손절된다. 50일선 이탈 청산은 758건 평균 +10.76%다. 손절된 거래의 43%는 40거래일 뒤 pivot 위로 돌아와 있었다. 손절폭이 이 종목들의 일상 변동폭보다 좁다.
3. **1순위 개선안은 손절을 변동성 기준(ATR×3)으로 넓히는 것이다.** 설계 t 1.70→2.36, 검증 t 1.74→2.64로 두 구간 모두 좋아졌다. 상위 1%를 빼도 t 2.06, 상위 5종목을 빼도 t 3.00이라 강건하다. 대가도 있다. 건당 최악 손실이 -12.6%에서 -29.2%로, 하위 1% 분위가 -8.7%에서 -22.4%로 깊어진다.
4. **효과 없거나 오히려 나쁜 안**: 갭 돌파 제외, 본전 스탑, 트레일링, MA20·MA10 청산, RS 상위 N%, 코스피>MA200. 같은 날 거래량으로 돌파를 확인하는 안(1.4x)은 t 3.40으로 좋아 보이지만 **룩어헤드**다. 룩어헤드를 없앤 판(확인 후 다음날 시가에 진입)은 t 2.05로 기준선(2.42)보다 못하다.

## 4. 해석 — "수익을 내려면"

- 심11의 기대수익은 **소수의 대형 추세**에서 나온다(상위 10% 거래가 총합의 250%). 그래서 필요한 개선은 진입을 더 까다롭게 거르는 쪽이 아니라 **그 추세에 끝까지 붙어 있게 하는 쪽**이다. -7.5% 고정 손절은 추세 초입 종목의 정상 흔들림(ATR×3 중앙값 12%)에 걸려 44%를 잘라낸다. 그 거래의 43%는 결국 올라갔다.
- 어떤 안을 써도 2023·2024년은 0 근처이거나 마이너스이고, 2025년 상승장이 수익의 대부분이다. 개선안은 "상승장에서 더 벌기"이지 "약세장에서 지키기"가 아니다. 약세장 방어 수단으로 시험한 시장 필터들은 설계 구간에서 오히려 나빠졌다.
- 운영 08~09월 성과(-2.60%, n=50)는 어느 안에서도 음수다(-1.6~-3.6). 최근 두 달은 이 전략에 맞지 않는 장이었고, 파라미터로는 해결되지 않는다.
