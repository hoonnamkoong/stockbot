# Sim0 학습 로그 + Sim10 선제 스위칭 설계

**작성일:** 2026-07-13
**출처:** office-hours 설계 세션
**상태:** 설계 합의 완료. 구현 미착수(별도 승인 필요).

## 배경 — 끊긴 가정

기존 가정은 "Sim0의 EOD 예측 정확도가 오르면 Sim10 성능이 오른다"였다. 그러나 검증 결과
**Sim10은 EOD 예측을 쓰지 않는다.** 재설계된 Sim10은 매 시각 `current_regime`(5회 스무딩된
*현재* 국면)을 읽어 하위 전략을 스위칭한다. 반면 대시보드의 2주 그래프는 "09시 첫 EOD 예측 vs
마감 실측"을 채점한다. 즉 채점하는 능력(하루 마감 예보)과 Sim10이 소비하는 능력(매시각 현재 국면
분류)이 다르다. 전자를 개선해도 후자가 좋아지지 않는다.

추가로 `current_regime`은 5회 다수결 확정이라 태생적으로 **후행**이다 — BEAR 확정 시점엔 하락이
이미 지나간 뒤다.

## 결정

### 1) 신호 방향 = 선제(anticipatory)
Sim10은 Sim0의 **다음 1시간(다음 스위칭까지) 예측**으로 미리 전환한다. 채점·학습 단위는 시간별,
라벨은 breadth가 아니라 **그 구간에 실제로 이긴 매매모델**(Sim4-1 / Sim5 / 현금).

### 2) 전용 학습 저장소 `sim0_training_log`
표시용 `intraday_score_log`에 얹지 않고 분리한다. 이유: 소비자가 다르고(오프라인 학습기 vs 프론트),
보존이 다르고(길게 vs 400 롤링), Phase B 라벨(매매 결과)은 나우캐스트 채점 로그에 낄 자리가 없다.
레포의 `adopted_registry` 분리 원칙(AI 캐시를 매매 상태에 섞지 말 것)과 동일. 단 채점 패스에서
이미 계산하는 pred/actual/gap을 재계산 없이 이 로그에 한 줄 append해 ①안의 장점을 흡수한다.

### 3) 동결된 피처 스키마 (Ⓐ 분포 요약)
로그 시작 후 빠뜨린 피처는 과거 소급 불가이므로, 파생값만이 아니라 **단면 분포를 넉넉히** 뜬다.
종목별 정체성은 제외한다 — 국면(시장 전체) 판단엔 과잉이고, 종목 단위는 하위 심(선택)의 몫이며
일별은 이미 `kospi_top100_close.csv`에 있다. code 없는 rate 배열은 정렬 불가라 "원시"가 아니므로,
종목별로 가려면 (code,rate) 전량이어야 하는데 그건 국면 목적 밖이다.

**매 시각 T 레코드:**
```
t, date, hour
breadth, momentum, trend, bull_score,
instant_regime, confirmed_regime, regime_confidence, sample
kospi_index, kospi_ret                          # 신규(현재 미수집, 소급 불가라 동결에 포함)
dist: { up, down, flat,
        mean, median, std,
        p10, p25, p75, p90,
        breadth@0, breadth@+1, breadth@+3,       # 임계별
        downtail@-3 }                            # 하락 꼬리 수
realized_next    # T+1h 백필: 실측 breadth → 실현 국면
best_model       # Phase B 백필: [T,T+1h] 실제 승자 (Sim4-1/Sim5/현금)
```

## 단계

- **Phase A (즉시):** 피처 로깅 시작. 라벨은 실현 다음 시각 국면(이미 재는 breadth 파생). 오늘부터
  학습셋 축적. 새 데이터 소스 없이 `_fetch_top100_breadth`가 이미 긁고 버리는 rate 배열로 `dist`
  요약을 만들어 넘기는 게 핵심 배선.
- **Phase B:** 매시각 각 전략 실현 수익 로깅 → `best_model` 라벨 승격(Sim10의 진짜 타깃).
- **Phase C:** h1 예측 적중률이 현재-국면 베이스라인을 이기면 Sim10을 선제 스위칭으로 전환.

## 가드레일

- **룩어헤드 금지:** T의 라벨은 T+1h에야 확정 → 학습에만 쓰고 T의 예측엔 절대 미투입.
  (현 나우캐스트 코드가 이미 준수 — 예측 후 나중에 채점)
- **콜드스타트:** 예측이 증명되기 전엔 실자본으로 안 굴린다. 데이터 수집(A/B)을 먼저 배포하고,
  h1 예측이 베이스라인을 이긴 뒤에 C를 켠다.
- **09시→EOD 그래프의 역할 재정의:** 폐기 말고 *Sim0 일별 편향 진단*으로(과대낙관 여부 튜닝).
  Sim10 학습 신호가 아님. 섞으면 무엇을 개선하는지 흐려진다.

## 첫 구현 스텝 (승인 시)

`trade_engine._fetch_top100_breadth`가 top100 각 종목 등락률을 이미 긁고 있다(현재 breadth/momentum만
남기고 버림). 그 rate 배열로 `dist` 요약을 산출해 Sim0에 넘기고, Sim0가 예측 시점에 피처를 기록,
채점 시점에 정답을 백필하는 배선이 Phase A.

## 범위 밖

- Phase C(Sim10 선제 전환 코드) — 예측 증명 후.
- 종목별/섹터 피처(Ⓒ) — 국면 목적 밖, 필요 시 별도.
