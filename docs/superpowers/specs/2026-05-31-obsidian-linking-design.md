# Obsidian 위키링크 추가 설계
2026-05-31

## 목표

본초서적 MD 파일들(8권, 25개 파일)에 약물 ↔ 질병/증상 양방향 마크다운 링크를 추가하여 Obsidian에서 의학 용어들의 연관성을 시각화.

## 입출력

**입력:** 
- `C:\Users\Hoon_DT\Desktop\본초서적\_md\` 하위 8개 책 폴더
- 25개 MD 파일

**출력:**
- 링크가 추가된 MD 파일들 (원본 대체)
- 마스터 사전: `drugs.json`, `diseases.json` (추출된 약물/질병 목록)

## 아키텍처

### 단계 1: 약물 & 질병 추출

**입력:** 각 MD 파일  
**도구:** Ollama qwen3:14b  
**프롬프트:**
```
이 한문 의학 텍스트에서 모든 약물명과 질병/증상명을 추출하라.
약물: 개별 약재 (黃耆, 甘草, 防風 등)
질병/증상: 질환명, 증상 (黃疸, 自汗, 痘症 등)
절대 텍스트를 바꾸지 말고, JSON으로만 반환하라.
형식: {"drugs": ["약물1", "약물2", ...], "diseases": ["질병1", "질병2", ...]}
```

**출력:** JSON (약물 목록, 질병 목록)  
**처리:** 배치 처리 (파일 1-2개씩, 병렬 가능)

### 단계 2: 정규화 & 통합

**입력:** 단계 1의 JSON 결과들 (25개)  
**처리:**
1. 모든 약물/질병을 수집
2. 링크 대상 정규화 (본문은 절대 수정 안 함)
   - 같은 의미 약물: 黃耆 = 黃芪 → `[[黃耆]]`로 통일된 링크만 생성
   - 길이 기준: 1자 약물(麻, 附) vs 2자 이상(甘草, 黃耆) 확인
   - **본문의 "黃芪"는 "黃耆"로 변경하지 않음** — 링크만 `[[黃耆]]`로 생성
3. 마스터 사전 생성
   - `drugs.json`: 링크 대상 정규화된 약물 목록 (원본 본문 표기는 모두 보존)
   - `diseases.json`: 링크 대상 정규화된 질병 목록 (원본 본문 표기는 모두 보존)

**출력:** 마스터 사전 (본문 원문 보존)

### 단계 3: 양방향 링크 삽입

#### 3-1. 정방향 링크 (약물/질병 → 위키링크)
**입력:** 각 MD 파일 + 마스터 사전  
**처리:**
- 마스터 사전의 약물/질병을 파일에서 찾아 마크다운 링크 `[[약물]]`, `[[질병]]` 추가
- 링크는 순수 마크다운 구문만 삽입 (원본 텍스트 변경 없음)
- 정규식: 약물/질병이 단어 경계에서만 매칭 (False positive 방지)
- 이미 링크인 부분은 건너뜀
- **주의:** 본문 텍스트 자체는 절대 변경 금지, 링크만 추가

**출력:** 링크가 추가된 MD 파일들 (원본 본문 완벽 보존)

#### 3-2. 역방향 링크 (약물 항목 → 관련 질병)
**입력:** 본초備要 약물 항목들 + 모든 파일에서 추출된 "약물 ↔ 질병" 동시 출현 데이터  
**처리:**
1. 전체 MD 파일 스캔: 같은 처방/항목 내에서 약물과 질병이 함께 나오는 경우 기록
   - 예: "黃疸" 섹션에 "黃耆" + "甘草" 포함 → `黃疸 → [黃耆, 甘草]`
2. 본초備要의 각 약물 항목 끝에만 "## 관련 질병" 섹션 추가 (기존 항목 수정 금지)
3. 그 약물이 관련된 모든 질병을 `[[질병]]` 형식으로 나열

**예시:**
```markdown
## 黃耆
- **性味**: 甘溫
...
[여기까지는 원본 그대로 보존]

## 관련 질병
- [[黃疸]]
- [[自汗]]
- [[痘症]]
```

**출력:** 역링크 섹션이 추가된 본초備要 MD 파일들 (기존 본문 완벽 보존)

## 데이터 흐름

```
┌─ 8권 MD 파일들
│
├─→ [Ollama 약물/질병 추출] ×25
│   └─→ JSON 결과들 ×25
│
├─→ [정규화 & 통합]
│   ├─→ drugs.json
│   └─→ diseases.json
│
├─→ [정방향 링크 삽입] ×25
│   └─→ 링크 추가된 MD 파일들
│
└─→ [역방향 링크 삽입]
    └─→ 본초備要 MD 업데이트
```

## 에러 처리

1. **Ollama 타임아웃:** 배치 재시도 (최대 3회)
2. **정규화 모호성:** 수동 확인 리스트 생성 (기록만, 실행 안 함, 본문 변경 금지)
3. **링크 충돌:** 기존 링크는 유지, 새 링크만 추가
4. **특수문자 처리:** 마크다운 이스케이프 필요 시 처리
5. **본문 변경 방지:** 링크 삽입 후 검증 (원본 텍스트가 수정되지 않았는지 확인)

## 검증

1. **추출 완성도:** 전체 25개 파일 처리 확인
2. **링크 정규화:** drugs.json, diseases.json 샘플 확인
3. **링크 정확도:** 5개 파일 샘플에서 링크 수 & 오류율 확인
4. **본문 보존:** 링크 추가 후 샘플 파일의 원본 텍스트가 변경되지 않았는지 확인 (diff로 확인)
5. **역링크 커버리지:** 본초備要의 약물 항목 중 역링크가 있는 비율 확인

## 성공 기준

- ✅ 25개 파일 모두 약물/질병 추출 완료
- ✅ drugs.json, diseases.json 생성 (각각 100+ 항목)
- ✅ 정방향 링크 삽입 완료 (모든 약물/질병이 위키링크화)
- ✅ 역방향 링크 완성 (본초備要의 약물 항목에 관련 질병 표시)
- ✅ **본문 완벽 보존:** diff로 확인 시 링크만 추가되고 원본 텍스트 무변경
- ✅ Obsidian에서 그래프 뷰로 약물-질병 네트워크 시각화 가능

## 구현 순서
