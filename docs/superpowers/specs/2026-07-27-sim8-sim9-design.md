## 심8. 선행매집 (C-2 × A-2′)

### 두 이론이 붙는 이유

> George & Hwang (2004, JF): 52주 고점이 심리적 앵커라서 **좋은 정보가 가격에 늦게 반영된다.**
> Kyle (1985): 그 지연 구간에서 **정보거래자는 이미 사고 있다.**

앵커링이 "왜 늦는가", 스마트머니가 "누가 먼저 아는가"를 설명한다. 심8은 **정보 반영 지연 구간**을 잡는다.

**Sim1과 정확히 반대 시점이다.** Sim1은 심리가 터질 때 사고, 심8은 심리가 아직 안 터졌을 때 산다.

### 진입/청산식

```python
# 좌표
nearness = price / w52_hgpr                       # 0~1, 1.0이면 신고가
pos      = (price - w52_lwpr) / (w52_hgpr - w52_lwpr)

# 정보축 — 거래대금으로 정규화 (절대 수량은 종목 크기에 오염됨)
frgn_r = frgn_fake_ntby_qty * price / max(amount, 1)
orgn_r = orgn_fake_ntby_qty * price / max(amount, 1)
info   = z(frgn_r) + z(orgn_r) + z(foreign_change)
info  *= 1.3 if (frgn_r > 0 and orgn_r > 0) else 1.0    # 외인·기관 합의 가중

# 군중축 — 개인이 아직 안 왔는지 (Sim1과 필드 공유)
crowd = z(unique_posters)

# ── 게이트 ────────────────────────────
거래대금 >= 10억
w52_hgpr > 0 and w52_lwpr > 0
nearness >= 0.85

# ── 진입 A: 매집 단계 (사이징 절반) ───
0.85 <= nearness < 0.98  AND  info > 1.5  AND  crowd < 0

# ── 진입 B: 돌파 단계 (나머지 절반) ───
nearness >= 1.00  AND  info > 0  AND  z(amount) > 0

# ── 청산 ──────────────────────────────
info 부호 반전  OR  nearness < 0.85  OR  트레일링 스탑(base_simulator)
```

### 기존 심에 없는 요소 5가지

1. **2단 피라미딩** — 기존 심은 전부 한 번에 사고 판다. 심8은 매집 절반 + 돌파 절반.
2. **정보축 지속성** — `notifier.py`에 `sparkline_frgn`/`sparkline_orgn` 5일 누적 한 줄 추가(sparkline_posts 옆). 하루 순매수는 노이즈, 연속이 매집. v1에는 없어도 됨.
3. **외인·기관 합의 가중** — 정보거래자 다수가 같은 방향이면 강한 신호(Kyle).
4. **거래대금 정규화** — 순매수 절대량으로 z를 내면 대형주가 항상 이긴다. Sim1의 `buzz>=500`과 같은 함정을 처음부터 차단.
5. **Sim1 교차 로그** — 같은 종목을 심8이 먼저 잡고 Sim1이 나중에 잡으면 "정보 → 심리 → 가격" 순서의 실증. 두 심이 서로를 검증한다.

### 데이터

| 필드 | 상태 |
|---|---|
| `w52_hgpr`, `w52_lwpr` | ✅ 보유, **아무 심도 안 씀** |
| `frgn_fake_ntby_qty`, `orgn_fake_ntby_qty` | ✅ 보유, **아무 심도 안 씀** |
| `foreign_change`, `amount` | ✅ 보유 |
| `unique_posters` | ⏸ Sim1 작업에서 추가 (파싱 1줄) |
| `sparkline_frgn/orgn` | ⏸ notifier 1줄 + 5일 대기 (요소 2용, v1 불필요) |

**네트워크 콜 추가 0.**

### 한계

52주 고점이 **언제** 찍혔는지 모른다(값만 있고 날짜 없음). 앵커 신선도를 구분할 수 없다. KIS 일봉 백필이 들어오면 해소된다.

## 심9. 갭소진 (Gap-Fade Rebound) — 실측 검증 완료

### 가설

> 급등주는 갭으로 오르고 장중에 되밀린다. 되밀림이 과도할수록 다음날 되돌아온다.

**레퍼런스**: **Lou, Polk & Skouras (2019, JFE)** "A Tug of War: Overnight Versus Intraday Expected Returns".

### 실측 (2026-06-01 ~ 07-27, 41거래일 · 225종목 · 1,097 종목-일)

데이터: `trending_integrated_2026-06/07.xlsx` 월별 스냅샷.
종가는 다음 거래일 행의 `전일종가`로 복원(58.1% 확정, 나머지는 마지막 스냅샷 — 오차 중앙값 0.00%, 86%가 0.5% 이내). 시가는 09:02 첫 스냅샷 근사.

**구조**: 갭 평균 **+5.21%**, 장중 평균 **−2.34%**. 하루 수익이 개장 전에 결정되고 장중은 되돌림.

**Tug-of-war 재현**: 갭 vs 당일 장중 상관 **−0.289**, 갭 vs **익일** 장중 상관 **−0.129**. 논문 예측(음) 일치.

**격자 (수수료 0.21% 왕복 차감 후 +1일 순수익 %)**

| 갭 > | 장중 < 0 | < −1 | < −2 | **< −3** |
|---|---|---|---|---|
| +2% | +1.41 | +1.62 | +1.92 | +2.49 |
| **+3%** | +1.96 | +2.14 | +2.45 | **+2.98** |
| +4% | +1.70 | +1.86 | +2.10 | +2.52 |
| +5% | +2.00 | +2.14 | +2.43 | +2.81 |
| +7% | +2.48 | +2.67 | +2.97 | +3.47 |

표면 전체가 한 방향으로 단조 기울어 있다 — 특정 칸을 고른 게 아니라 노이즈가 아니라는 증거.
**되밀림 깊이가 주신호, 갭 크기는 부차적**(`장중 < −3` 열이 모든 갭 구간에서 최고).

**채택: 갭 ≥ +3%, 장중 ≤ −3%** — +1일 순 **+2.98%**, 승률 **59.7%**, n=134, 발생률 21.6%, +3일 순 +4.93%. 기저 +1일 순 **+0.21%**.
극단 칸(갭>7, +3.47%, n=95)을 안 고른 이유는 과적합 회피.

**반증된 방향**: gap-and-go(갭>+2% & 장중>0)는 +1일 −0.57%로 기저 이하. 원래 제안한 방향이 틀렸고 실측이 정반대를 가리켰다.

### 진입/청산식

```python
open_px = stck_oprc          # inquire-price 응답, 필드 1줄 추가 (문서 확인 필요)
prev_cl = stck_sdpr          # 이미 파싱 중
gap     = (open_px / prev_cl - 1) * 100
intra   = (price / open_px - 1) * 100

# ── 게이트 ──────────────────────────────────────
거래대금 >= 10억
open_px > 0 and prev_cl > 0
현재시각 >= 14:30                     # 되밀림 확정 후에만. 조기 진입 금지

# ── 진입 ────────────────────────────────────────
gap >= +3.0  AND  intra <= -3.0

# ── 청산 ────────────────────────────────────────
익일 종가 무조건 청산 (타임스탑 1일)
OR 익일 장중 +3% 도달 시 조기 익절
OR 손절 -3%
```

**진입 시각 게이트(14:30)가 핵심.** 되밀림 확정 전에 사면 더 밀린다. 스크래퍼가 15:03·15:33에 도니 그때 진입 = 종가 근처 체결.
**타임스탑 1일도 필수.** +5일 수익이 −0.39%로 무너진다.

### 데이터

`stck_oprc`만 추가하면 된다. **네트워크 콜 0** (`inquire-price` 응답에 이미 `stck_sdpr`를 읽고 있어 같은 output 블록에 있을 가능성이 높다 — 문서 확인 1회 필요). 없으면 일봉 1콜/종목.

### 배포 게이트

+1일 순수익 ≥ +2.0% (실측의 2/3) / 승률 ≥ 55% / **월 거래수 ≤ 25건**(Sim1이 69건·수수료로 실패한 전례).

### 한계

시가가 09:02 근사로 검증됨 — 진짜 시가로 재검증하면 갭이 작아져 임계값을 낮춰야 할 수 있다. 유니버스가 급등주 편향(기저 +5일 −1.12%가 증거). 거래대금 필터 없이 검증했으므로 실전 슬리피지가 초과수익을 깎는다.

## 심9-1. 돈치안 채널 돌파 (Turtle) — 검증 보류

**레퍼런스**: Richard Dennis & William Eckhardt, 터틀 트레이딩 실험(1983).

⚠️ **심9와 성격이 반대다.** 심9는 1일 역추세, 심9-1은 다일 추세추종. Sim4의 momentum/daytrading 관계(같은 전략의 시간축 변형)와 다르다. 묶는 근거는 "차트 데이터 계열"뿐. 나중에 독립 번호로 옮기는 게 자연스러울 수 있다.

```python
hist    = daily_history[-20:]
ch_hi   = max(h.high for h in hist)          # 고가 기준 (원 터틀 충실)
ch_lo10 = min(h.low for h in hist[-10:])

# 게이트: 거래대금 >= 10억, len(hist) >= 20
# 진입: price > ch_hi  AND  z(amount) > 0
# 청산: price < ch_lo10  OR  손절 = 진입가 - 2*ATR(20)
```

### ⚠️ 선행 조건: KIS 일봉 백필

**현재 데이터로 검증 불가.** 20일 채널 신호가 41거래일 전체에서 **4건**. 유니버스가 동적이라 종목당 평균 4.9일만 관측된다.

필요 작업:
1. `get_daily_ohlcv()` — `inquire-daily-itemchartprice` / `FHKST03010100` (분봉 `FHKST03010200`이 이미 [kis_data_provider.py:121](../../../src/trade/kis_data_provider.py#L121)에 구현돼 있어 같은 계열·같은 `_get()` 재사용)
2. `eod_data.yml`에 배선 — 이미 16:00 KST cron + KIS 토큰 처리 + db-data 배포 경로 보유. 장중 스크래퍼에 붙이면 같은 일봉을 하루 5~6번 재수신하는 낭비.
3. 100일 백필 1회 → 이후 증분 1행/일. `data/ohlcv_YYYY-MM.csv` (db-data는 `data/*.csv`만 실어 나른다)
4. **수정주가 옵션(`FID_ORG_ADJ_PRC`) 확인 필수** — 액면분할·증자 시 과거 봉이 어긋나면 채널·앵커·RS가 조용히 망가진다.
