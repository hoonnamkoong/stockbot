## 0. 결론 먼저

> **09-29 갱신: 게이트 확정 = 약한횡보 + 하락 + 매우하락(§9).** 아래 1~5는 최초 분석이다. 5번 "게이트 비용"은 사용자가 하락계를 게이트에 넣어 해소했다. 파라미터는 바꾸지 않는다. 공통 파라미터로 충분함을 §9에서 확인했다.

1. **심5는 약한횡보에 배정한다.** 조건(진입·청산·손절·보유한도)을 바꿔 가며 잰 거의 모든 조합에서 강한횡보 성과가 약한횡보보다 나쁘다. 강한횡보에서는 일별 클러스터 t가 음수이고, 이 결과는 설계 구간, 검증 구간, 275종목 패널에서 모두 같다(§3).
2. **컨셉(레인지 저점 매수 = 평균회귀)은 유지한다.** 진입에 **RSI2 과매도 확인**을 더하고 청산을 **RSI2 과열(>70)**로 바꾼다. 손절은 −3%에서 **−5%**로, 타임스탑은 7일에서 **10일(달력일)**로 넓힌다. 채널 상단 트레일링은 없앤다(§4).
3. 약한횡보 게이트 아래 거래 단위 성과(top100)
   - 현행: 설계 −0.34%/건, t −1.40 → 검증 +0.78%/건, t +0.80
   - 권장: 설계 **+0.50%/건, t +2.59, 승률 65%** → 검증 **+1.01%/건, t +2.76, 승률 69%**
4. **주의 1.** 5슬롯 포트폴리오로 보면 약한횡보 게이트 아래에서 권장안의 누적수익은 현행과 같은 수준이다(+20.6% 대 +23.6%, 28개월). 개선은 MDD(−7.5% 대 −11.3%)와 거래 단위 기대값에서 나온다. 누적수익 개선은 입증되지 않았다(§5).
5. **주의 2(범위 밖, 결정 필요).** 이 전략은 원래 **하락·매우하락 국면에서 가장 잘 번다**(현행 +1.07%/+1.90%, 권장 +0.92%/+3.57%, 일별 t 2~2.8). "배정 국면에서만 신규 진입" 규칙을 적용하면 약한횡보는 설계 구간 109일, 검증 구간 24일만 열린다. 그래서 심5는 대부분의 날에 쉬게 되고, 게이트가 없을 때보다 누적수익이 크게 준다(현행 설계 구간 +69.6% → +8.6%)(§6).

## 4. 약한횡보 안에서의 최적화

### 4.1 선택 절차

1. 설계 구간의 약한횡보 게이트 거래만으로 일별 t를 순위 매긴다(n ≥ 60). 상위권은 거의 전부 **"채널 저점 + RSI2 과매도" 진입 × RSI2>70 또는 MA5 청산 × 넓은 손절(−5/−8/ATR2) × 10cd**였다(`r3_s2_out.txt` 상위 25).
2. 운영 제약으로 ATR×2 손절은 제외했다. `range_history`에 종가만 있어 고가·저가가 없기 때문이다. 퍼센트 손절만 남긴다.
3. 진입 이웃과 청산 이웃을 확인했다(아래 표). 고원이 확인됐다.
4. RSI2 문턱 10과 15는 설계 거래 단위 t가 사실상 같았다(2.02 대 2.06). **설계 구간 5슬롯 포트폴리오**(+1.7% 대 +12.6%, MDD −8.4 대 −6.9)로 15를 골랐다. 검증 구간 값은 선택에 쓰지 않았다.

## 6. 한계와 범위 밖 발견

1. **(결정 필요) 게이트 비용.** 평균회귀는 하락·매우하락 국면(전일 라벨)에서 가장 강하다. 현행 기준 하락 +1.07%/t 2.73, 매우하락 +1.90%/t 2.29이고, 권장 기준 +0.92%/t 2.03, +3.57%/t 2.77이다. "약한횡보에서만 신규 진입"하면 이 구간을 버린다. 게이트 없는 현행이 설계 구간 +69.6%인 것도 대부분 이 구간에서 나왔다. 사용자 결정(배정 국면에서만 진입)을 따르면 심5는 전체 거래일의 약 16%만 일한다. 약한횡보 + 하락계 허용 같은 확장은 이 조각의 범위 밖이라 제안만 한다.
2. **국면 라벨의 예측력 부재.** R1 판정대로 regime6는 "현재 상태 기술"이다. 이 배정은 "전일 라벨이 약한횡보일 때 진입한 거래"의 사후 성과다. 검증 구간 약한횡보는 24일, 권장 규칙 기준 58건(20진입일)뿐이라 검증 t 2.76의 신뢰구간이 넓다.
3. **일봉 근사.** 진입가는 종가다. 운영은 장중 현재가로 판정하고 체결한다. 장중에 RSI2<15이던 종목이 종가에서 아닐 수 있고, 반대도 가능하다. 손절은 일중 저가로 판정했다(운영은 런 주기마다 판정하므로 더 늦게, 더 깊게 체결될 수 있다. 과거 관찰 기록: 장중 손절이 설정보다 0.5~2.5%p 깊다).
4. **유니버스.** 연구는 야후 top100 고정 패널이다(현재 시점 구성, 생존 편향 있음). 운영은 `get_universe()`가 `fetch_top100(limit=100)`을 부르고, 실패하면 None을 돌려줘 파이프라인 후보(버즈)로 돌아간다. 브리핑의 "get_universe=None"과 코드가 다르니 다음 조각에서 확인할 것. 275종목 패널에서는 약한횡보 알파가 0 근처라서 **버즈·소형주 폴백 시 이 결과를 기대하면 안 된다**.
5. **`range_history`의 당일 포함 여부.** 연구는 직전 20일(당일 제외)을 전제로 했다. 장중 `range_history`에 오늘의 미완성 봉이 섞이면 채널 저점이 현재가와 같아져 zone 조건이 뜻을 잃는다. 심9-1 독스트링이 같은 문제를 경고한다. 구현 조각에서 KIS·네이버 경로 둘 다 확인할 것.
6. **모델링하지 않은 것.** 쿨다운(손절 3일·트레일 2일·타임 1일), 부분 체결, 호가 단위, 슬리피지(수수료 0.26%만 반영).
7. 청산 이웃(§4.3)은 RSI2<10 진입으로 쟀다. 최종 RSI2<15에서는 청산 조합 16칸을 다시 재지 않았다. 진입 이웃 표로 보면 10과 15의 성질이 같다.

RSI2 정의: Wilder RSI, 기간 2(α = 1/2 지수평활). 입력은 `range_history`(직전 20일 종가, 과거→최신) 뒤에 **현재가**를 붙인 21개 값이다. 첫 값의 영향은 0.5^20 ≈ 1e-6이라 무시할 수 있다. 연구 하네스(`r3_lib.rsi2`)는 pandas `ewm(alpha=0.5, adjust=False)`로 계산했고, 하락분 평균이 0이면 RSI=100(분모 NaN → 50으로 채운 연구 구현과 다르다. 구현 시 "하락 없음 = 100"으로 둘 것. 과매도 판정에는 영향이 없다).

## 8. 의사코드(구현 조각이 그대로 옮길 것)

```text
def rsi2(closes):                       # closes: 과거→최신, 마지막 = 현재가
    up = dn = None
    for k in 1..len(closes)-1:
        d = closes[k] - closes[k-1]
        u, v = max(d, 0), max(-d, 0)
        up = u if up is None else 0.5*up + 0.5*u
        dn = v if dn is None else 0.5*dn + 0.5*v
    if dn == 0: return 100.0
    return 100 - 100 / (1 + up/dn)

def decide_sideways(view, candidates, current_prices, regime6):
    orders = []
    # ── 1. 청산: 국면과 무관하게 항상 ─────────────────────────
    for code, p in portfolio:
        cur = current_prices[code]; if cur <= 0 or p.avg_price <= 0: continue
        pr = (cur / p.avg_price - 1) * 100
        if pr <= STOP_PCT (-5.0):                     SELL "하드 손절", cooldown 3; continue
        hist = 해당 종목 후보의 range_history(직전 20일 종가)
        if len(hist) >= MIN_HISTORY and rsi2(hist + [cur]) > EXIT_RSI2_MIN (70):
                                                       SELL "RSI2 과열 청산", cooldown 2; continue
        if (today - entry_date).days >= TIMEOUT_DAYS (10):
                                                       SELL "타임 스탑", cooldown 1; continue
        # hist가 없으면(후보 밖) RSI2 청산은 건너뛰고 손절·타임스탑만 본다 — 판정 불가를 '청산 조건 미충족'과 섞지 말고 funnel에 'exit_no_hist'로 센다
    # ── 2. 진입 게이트 ─────────────────────────────────────
    if regime6 not in ALLOWED_REGIMES ({'약한횡보', '하락', '매우하락'}):   # None(판정 불가)도 진입 금지
        funnel 'regime_gate'; return orders
    # ── 3. 진입 ──────────────────────────────────────────
    for stock in candidates (정렬: price/low 오름차순, 동률은 code 오름차순):
        if held >= MAX_HOLDINGS: break
        보유/당일매도/쿨다운 → skip
        price, amount 필드 부재 / 값 미달(amount < MIN_AMOUNT) → skip (현행 funnel 유지)
        hist = range_history (직전 20일 종가, 당일 미포함)
        if len(hist) < MIN_HISTORY (20): skip 'no_channel'
        low, high = min(hist), max(hist)
        if (high - low) / low * 100 < MIN_WIDTH_PCT (8):   skip 'narrow_channel'
        if price > low * (1 + LOW_ZONE (0.03)):            skip 'not_near_low'
        if daily_change <= DAILY_CRASH_PCT (-2.0):         skip 'daily_crash'
        r = rsi2(hist + [price])
        if r >= ENTRY_RSI2_MAX (15):                       skip 'rsi2_not_oversold'
        qty = int(nav * POSITION_WEIGHT / price); if qty <= 0: skip
        BUY qty @ price, reason "[레인지] 저점+과매도 (채널폭 w%, RSI2 r)"
        held += 1
    return orders
```

- 운영 게이트의 국면은 리베로 설계 §4.4의 확정 regime6(10:00 전에는 전일 확정, 이후 장중 확정)을 쓴다. 연구는 이보다 보수적인 전일 라벨로 검증했다.
- 정렬 규칙은 연구의 포트폴리오 근사와 같다(`price/low` 오름차순). 현행 코드는 후보 순서대로 채우므로 정렬을 명시적으로 추가해야 연구와 같아진다.
