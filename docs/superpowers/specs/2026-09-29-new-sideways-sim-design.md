# 새 횡보 심 컨셉 연구 (R4) — 약한횡보·강한횡보별 후보 비교

- 작성: 2026-09-29, 조각 R4 (스펙 항목 S7)
- 전제 설계서: `2026-09-29-libero-regime6-design.md` (리베로 6단계)
- 상태: **연구 결과 + 구현용 설계**. 코드 변경 없음. 새 심은 `tradeable=false`(관찰 전용).
- 심5 배정은 R3가 정한다. 이 문서는 **두 횡보 각각의 최선 후보**를 모두 내놓고, 조율자가 R3 결과를 보고 반대쪽을 고른다.

> **정정 메모 (2026-10-02, 배포 코드 재생 검증 `2026-10-02-sim14-replay-validation.md`)** — 아래 원 수치는 이력으로 남긴다.
> - W5 "n=168, 건당 +2.51%, t=+2.67"은 **슬롯 제약 없는 신호 목록** 기준이다. 실제 Sim14(5슬롯·NAV 19%)는 같은 창에서 113건, 일별 t **1.80**, NAV **+40%**, MDD **−11%**다.
> - 장기(2005~, 상장폐지·스파이크 보정)로는 연 +3.1%, β조정 알파 **+0.2%/년(t 0.10)** — 알파가 없다.
> - 신호 품질은 강한횡보(일별 t 1.85)가 기타 국면(t 4.20)보다 **낮다**. 강한횡보 게이트가 하는 일은 알파 선택이 아니라 **β(0.66→0.21)·MDD 축소**다.
> - §7.1 의사코드는 진입 당일에도 MA10을 판정했는데 R4 백테스트는 다음 날부터 봤다(설계서 안의 의사코드↔백테스트 불일치). 의사코드를 백테스트 쪽으로 고쳤다(진입 당일은 MA10·만기 판정 제외, −5% 손절은 당일에도 유지).

- 조율자 선택 규칙: R3가 심5를 **약한횡보**에 배정 → 새 심 = **W5(강한횡보)**. R3가 심5를 **강한횡보**에 배정 → 새 심 = **S1(약한횡보)**. 단, S1은 모집단을 바꾸면 효과가 사라지므로 "관찰 전용으로 켜고 5거래일이 아니라 약한횡보 30거래일 이상 누적 후 판정"을 조건으로 건다. 약한횡보에는 **새 심을 두지 않는 선택지(현금)**도 동등하게 합리적이다 — 7개 후보 중 두 모집단 모두에서 양(+)인 것이 없다.
- 부수 발견 (조율자 선행 결과와 충돌): **RSI2·3일 연속하락 반등은 강한횡보에서 오히려 약하다.** RSI2<10→MA5 5일은 강한횡보 t=+0.43(top100)·t=−1.77(275종목), 기타 국면(상승·하락 추세)에서 t=+5.01. "9월에 좋았다"는 월 단위 관찰은 국면 조건부로 재면 재현되지 않는다.
- 갭 페이드(갭다운 시가 매수·당일 종가 청산)는 강한횡보에서 **유의한 음(−)**: 검증 t=−3.68. 갭은 되돌림이 아니라 지속됐다. 갭 전략 전면 기각.

## 6. 추천

### 6.1 강한횡보용 새 심 — "수축 돌파형" (W5, q=0.10)

발상: 시장 전체는 방향 없이 크게 흔들리는데(고변동 횡보), **개별 종목 중 자기 변동성이 바닥까지 눌려 있던 종목**이 20일 고가를 뚫는 순간은 시장 소음과 무관한 종목 고유 재료의 시작일 가능성이 높다(Crabel의 수축→확장). 반대로 시장 소음에 반응하는 되돌림 전략(RSI2, 갭 페이드, 급락 반등)은 강한횡보에서 전부 0 또는 음(−)이었다.

### 6.2 약한횡보용 새 심 — "2일 과매도 반등형" (S1, RSI2<10, 3일)

발상: 조용한 장에서의 짧은 과매도 되돌림(Connors). 다만 근거가 약하므로 **관찰 전용으로만** 두고, 약한횡보 30거래일 누적 후 일별 t ≥ 2가 아니면 폐기. 대안은 약한횡보에 새 심을 두지 않는 것.

## 7. 구현용 의사코드

공통: `tradeable=false`, `needs_buzz=false`, 자체 유니버스 = 운영 top100. 사이징 = 원금(budget+realized_pnl) × 19%, 최대 5종목. 국면 = 전일 확정 `regime6`(리베로 t−1 판정; 당일 라벨을 쓰면 룩어헤드). 청산 로직은 국면과 무관하게 매 루프 실행.

### 7.1 W5 수축 돌파형 (강한횡보)

```
# ── 장 시작 전 또는 당일 첫 루프에서 1회 (종목별, 확정 일봉만 사용) ──
bars = kis.get_daily_history(code, days=90)      # 오래된→최신, 당일 진행봉 없음 (TTL 1일 캐시)
if len(bars) < 80: skip                           # 밴드폭 60일 분위 + MA20 → 최소 80봉
close = [b.close for b in bars]; high = [b.high for b in bars]
bw[k] = 4*std(close[k-19..k]) / mean(close[k-19..k])     # k = 최근 60개 확정일 각각
squeeze = bw[-1] <= quantile(bw[-60:], 0.10)             # 전일(t-1) 밴드폭이 자기 60일 하위 10%
hi20 = max(high[-20:])                                   # 전 20거래일 최고가(당일 제외)
amt5 = mean(amount[-5:])                                 # 전일까지 5일 평균 거래대금
eligible = squeeze and amt5 >= 1e9

# ── 60초 루프: 진입 ──
if regime6_prev == '강한횡보' and eligible and code not in holdings
   and len(holdings) < 5 and code not in exited_today:
    if price_now > hi20:
        buy(code, qty = floor(NAV*0.19 / price_now))
        pos.entry = fill_price; pos.stop = fill_price*0.95; pos.days = 0

# ── 60초 루프: 청산 (항상) ──
for pos in holdings:
    if price_now <= pos.stop: sell('손절 -5%')                       # 장중 즉시
    if 15:15 <= now < 15:20 (마감 직전 루프) and pos.entry_date != today:   # 진입 당일 제외(10-02 정정, 백테스트와 일치)
        ma10 = mean(close[-9:] + [price_now])                         # 확정 9봉 + 현재가
        if price_now < ma10: sell('MA10 이탈')
        elif pos.days >= 10: sell('10거래일 만기')
# 쿨다운: 청산한 종목은 그날 재진입 금지(백테스트 = 청산 다음 날부터 재진입 허용과 동일)
```

- 체결 가정: 백테스트는 `max(시가, hi20) + 0.10%`에 체결. 60초 루프는 돌파 확인 뒤 최대 60초 늦게 사므로 **실제 체결가는 이보다 높다**. 관찰 심에서 `신호가(hi20)`와 `가상 체결가(현재가)`를 둘 다 기록해 슬리피지를 실측할 것. 시가가 이미 hi20 위(갭 돌파)면 09:00~09:01 첫 루프에서 시가 근처에 사야 백테스트와 같다.
- 백테스트 손절 판정은 일봉 저가 기준이라 장중 루프(현재가)와 거의 같다. 진입일 당일 손절도 반영했다.

### 7.2 S1 2일 과매도 반등형 (약한횡보)

```
# ── 마감 직전 루프(15:15~15:20)에서만 진입 판정: "종가" = 그 시점 현재가 ──
closes = range_history[-19:] + [price_now]                 # 확정 19~20봉 + 현재가
rsi2 = RSI(closes, period=2, wilder_alpha=0.5)
if regime6_prev == '약한횡보' and rsi2 < 10 and amt5 >= 1e9
   and code not in holdings and len(holdings) < 5:
    buy(code, qty = floor(NAV*0.19 / price_now))

# ── 청산 (항상, 마감 직전 루프) ──
ma5 = mean(range_history[-4:] + [price_now])
if price_now > ma5: sell('MA5 회복')
elif pos.days >= 3: sell('3거래일 만기')
# 손절 없음(백테스트에 없음 — 넣으면 다른 전략이다)
```

- 종가 조건을 15:15~15:20 현재가로 해석한다. 한국장은 15:20~15:30 동시호가라 **현재가 ≠ 종가**. 백테스트는 종가 체결이므로 관찰 기간에 차이를 기록할 것.
- 동시 신호가 5개를 넘으면 RSI2 낮은 순으로 채운다(백테스트는 종목코드 순 — 정렬 효과는 미검증).

## 9. 한계

1. **생존 편향**: top100은 "현재" 운영 목록을 과거에 소급 적용. 돌파형(W5)은 나중에 대형주가 된 종목이 유리하게 잡히므로 편향 방향이 W5에 우호적이다. 275종목에서 t가 2.67→1.55로 줄어든 것이 그 크기의 단서.
2. **표본**: 강한횡보 W5 q0.10 설계 77건·검증 91건. 설계 t=1.74로 단독으로는 5% 유의 미달. 약한횡보 검증 구간은 25거래일뿐이고 그 기간 장 전체가 올랐다(기준선 t=4.79).
3. **두꺼운 꼬리**: W5 중앙값 음(−), 2024년·2026-09 음(−). 소수 대박 종목이 평균을 만든다 → 관찰 초기 몇 주는 손실이 정상일 수 있다.
4. **포트폴리오 근사**: 실현 NAV 기준, 평가손 미반영이라 MDD 과소추정. 동시 신호 우선순위는 종목코드 순.
5. **체결**: 일봉 근사. 장중 돌파 후 60초 지연·동시호가 차이는 반영 안 됨(슬리피지 0.10%만 가정).
6. **국면 게이트 효과와 전략 효과의 분리 미완**: 강한횡보 기준선이 약 0이라 W5의 양(+)은 대부분 전략 자체로 보이나, 기준선 대비 초과수익 t는 따로 재지 않았다.

## 10. 범위 밖 발견

- RSI2 단기 반전은 **추세 국면(기타: 상승·하락)** 에서 가장 강하다(top100 t=5.01, 275종목 t=2.83, 설계·검증 모두 양). 횡보 전용이 아니라 오히려 "추세 중 눌림" 컨셉. 다른 심 설계 때 참고.
- 야간 보유(종가→익일 시가)는 전 국면에서 음(−)(t −1.5 ~ −6.9). 한국 대형주는 이 기간 장중 수익 > 야간 수익.
- 갭 뒤 시가 매수는 방향과 무관하게 당일 음(−): 갭다운은 **이어서 더 빠지고**(강한횡보 검증 −1.06%, 비용 0.36% 넘는 손실), 갭업은 **장중에 밀린다**(강한횡보 검증 갭업≥2% −1.10%, t −4.44). 즉 갭다운 페이드도 갭업 추종도 안 된다. 갭 계열 매수 컨셉은 한국 top100에서 재검토 불요(갭업 공매도는 운영상 불가라 미검증).
