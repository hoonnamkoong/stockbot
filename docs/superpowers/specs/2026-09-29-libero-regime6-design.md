## 0. 한 줄 결론

방향 축 = **"20일선 위 종목 비율(ab20)" + "균등지수 10일 수익률(ret10)" 합성 점수 D**를 대칭 문턱과 2일 확정으로 5단계로 나누고, 횡보만 **균등지수 10일 실현변동성(vol10) 0.98%** 문턱으로 약한/강한으로 나눈다. 당일 변화는 별도 규칙 없이 **오늘 현재가가 ab20·ret10·vol10에 그대로 들어가는 방식**으로 반영된다(추세 × 당일의 하이브리드). 사후 정답과의 3단계 일치율이 현행 42%/33%(표본 내/외)에서 51%/55%로 오르고, 전환 횟수는 연 52/81회에서 47/39회로 준다.

**단, 어떤 후보도 "다음 5·20일 수익률이 매우하락<…<매우상승 순으로 단조"를 만족하지 못했다(현행 포함).** 극단 국면 두 곳이 모두 다음 수익률이 높은 U자형이고, 표본 내(2023-06~2025-06)와 표본 외(2025-07~2026-09)에서 부호가 뒤집힌다(§5.3). 그래서 이 국면은 **"지금 시장이 어떤 상태인가"를 기술하는 분류기**로 설계했다. 다음 수익률을 예측하는 신호로 쓰면 안 된다. 이 한계는 §7에 적었다.

## 1. 배경: 현행 리베로의 문제

`src/strategy/simulators/sim0_libero.py::classify_regime(breadth, momentum, trend)`

| 입력 | 운영 실체(코드 확인) |
|---|---|
| `breadth` | top100 당일 상승 종목 비율 % (`trade_engine._fetch_top100_breadth` → `_breadth_momentum`) |
| `momentum` | top100 당일 등락률 **중앙값**(%) — 평균이 아니다(`_breadth_momentum`이 `_median(rates)`) |
| `trend` | `_top100_trend_from_csv`: `output/kospi_top100_close.csv` 최근 10행에서 종목별 Kaufman 효율비(`_adx` = \|끝-시작\|/Σ\|일간변화\|×100)의 중앙값. 방향이 없고 장중에는 상수다 |

- BULL = breadth≥60 & momentum≥2.0 & trend≥20, BEAR = breadth≤40 & momentum≤−1.5 & trend≥15. `_confirm_regime`은 최근 5런(10분 간격, 약 50분) 최빈값이다.
- 따라서 BEAR는 "오늘 급락했나"를 보는 탐지기다. 소급 결과 평균 지속은 1.1~1.4일이고, 연 52~81회 전환한다(§5 B0). 다주 추세는 입력에 없다.

## 4. 권장안(방식 R) — 수식·임계값

모든 값은 **t일 기준으로 관측 가능한 것만** 쓴다. 장중에는 "오늘 종가" 자리에 현재가를 쓴다.

```
입력: P[i, t]  = 종목 i의 t일 종가(장중엔 현재가), top100
     r[i, t]  = P[i,t]/P[i,t-1] - 1
     EWret[t] = mean_i r[i,t]                   # 균등가중 지수 일간 수익률
     EW[t]    = Π(1+EWret)                       # 균등지수 레벨

ab20[t]  = 100 × #{i : P[i,t] > SMA20_i(t)} / #{SMA20이 있는 i}     # SMA20은 오늘 포함 20행
ret10[t] = EW[t]/EW[t-10] - 1
vol10[t] = std(EWret[t-9..t]) × 100                                  # 표본표준편차, %

D[t] = 0.5 × (ab20 - 50)/25  +  0.5 × clip(ret10 / 0.06, -1, +1)      # 범위 약 −1.5..+1.5
```

### 4.1 방향 5단계(대칭 문턱)

| 원시 단계 | 조건 |
|---|---|
| −2 매우하락 | D < −0.90 |
| −1 하락 | −0.90 ≤ D < −0.40 |
| 0 횡보 | −0.40 ≤ D < 0.40 |
| +1 상승 | 0.40 ≤ D < 0.90 |
| +2 매우상승 | D ≥ 0.90 |

- 문턱 0.40·0.90은 표본 내(2023-06-01~2025-06-30) \|D\|의 40%·80% 분위(0.407, 0.900)를 동결한 값이다. 분위(비대칭, −0.671/−0.165/0.588/1.038)도 비교했다. 대칭 문턱은 3단계 일치율이 비슷하면서(§5.2) "방향 없음 = 0 근처"라는 뜻이 곧게 서고, 사용자가 예로 든 2026-09를 횡보로 읽는다. 방향 단계 기준으로 9월 19거래일 중 횡보 17, 상승 2이고, 분위 문턱에서는 하락이 9일이다. vol10으로 약/강을 나누면 강한횡보 12, 약한횡보 5(09-21 이후), 상승 2다.
- **히스테리시스:** 원시 단계가 현재 확정 단계와 다를 때는 D를 현 단계 쪽으로 0.05 당긴 값으로 다시 판정한다. 그래도 다를 때만 이동 후보가 된다.
- **2일 확정:** 이동 후보가 같은 단계로 **2일 연속**일 때만 확정한다. 중간에 되돌아오면 후보를 초기화한다.

### 4.2 횡보의 약/강 분리

- 확정 방향 단계가 0일 때 `vol10 > 0.98` → **강한횡보**, 그 밖 → **약한횡보**.
- 0.98은 표본 내 vol10 중앙값을 동결한 값이다. 절대 문턱을 고른 이유: 과거 60일 분위(상대) 방식은 7~8월 폭등락 직후인 2026-09를 "상대적으로 조용함"으로 읽어 약한횡보로 판정했다. 사용자가 정의한 "일간 ±1~3% 등락 = 강한 횡보"와 맞지 않는다.
- vol10을 고른 이유: 변동성 창별로 "약/강 판정 → 다음 5일 실제 변동"을 보면 **vol10과 vol5만 표본 내·외 모두 방향이 맞았다**. vol20과 EWMA는 표본 내에서 역전됐다(아래 표).

| 변동성 지표(문턱=IS 중앙값) | IS 약/강 다음5일 변동% | OOS 약/강 다음5일 변동% |
|---|---|---|
| vol5 (0.92) | 1.04 / 1.24 ✅ | 1.10 / 1.87 ✅ |
| **vol10 (0.98)** | **1.06 / 1.21 ✅** | **1.11 / 1.80 ✅** |
| vol20 (1.06) | 1.19 / 1.04 ❌ | 0.92 / 1.82 ✅ |
| EWMA λ=.94 (1.09) | 1.20 / 0.98 ❌ | 1.02 / 1.83 ✅ |

| regime6 | current_regime(3단계, 파생) |
|---|---|

### 4.4 당일 변화의 반영(하이브리드) — 장중 운영

- 장중 매 런마다 `P[i,t]`에 네이버 현재가를 넣어 D·vol10을 새로 계산한다. 당일 급락은 ret10(1/10 가중)과 ab20(20일선을 깬 종목 수), vol10에 즉시 들어간다. "오늘 급락 = 바로 BEAR"가 아니라 "며칠 누적된 약세 + 오늘 한 번 더"여야 단계가 내려간다.
- **확정 규칙은 일 단위다.** 장중 값은 "오늘의 원시 단계" 후보로만 쓴다. 장중 확정 단계는 `(어제까지의 확정 상태, 어제 후보 카운트) + 오늘 장중 원시 단계`로 계산한다. 그러면 어제도 같은 방향으로 이동 후보였던 날에만 장중에 단계가 바뀐다. 현행의 "10분×5런 최빈값"은 폐기한다. 호출 주기가 평활 시간상수가 되는 문제(`trade_engine` 독스트링)가 이것으로 사라진다.
- **장중 시각:** 원시 단계는 09:10~09:30에 종가와 80~86%가 일치하고, 10:00 이후 90~95%로 안정된다(§5.5). 권장: **10:00 이전에는 전일 확정 국면을 유지**하고, 10:00부터 장중 원시 단계를 반영한다. 확정 규칙까지 적용하면 09:10에도 95%가 일치하므로 이 규칙은 보수적 안전장치다.
- 별도의 "당일 극단 보정"(breadth≤15 & momentum≤−2면 그날만 한 단계 하향, 반대도 대칭)은 **넣지 않는다**. 사후 정답 일치율 개선이 +1~3%p에 그쳤고, 전환 횟수는 연 47→56회(IS), 39→70회(OOS)로 늘었다(§5.4).

### 4.5 결손 시 동작(판정 불가 ≠ 횡보)

| 상황 | 동작 |
|---|---|
| 종가 CSV 행 < 21 또는 읽기 실패 | 판정 불가 → **직전 확정 regime6 유지**. `regime6_status='stale'`, 원인 로그. SIDEWAYS로 채우지 않는다 |
| 라이브 top100 수집 실패(None) 또는 표본 < 80 | 장중 갱신 생략, 직전 확정 유지(현행 `run()`의 "판단 불가 — 직전 국면 유지"와 같은 계약) |
| SMA20 계산 가능 종목 < 80 | ab20 판정 불가 → 위와 동일 |
| 직전 확정값도 없다(첫 실행) | regime6 = None, current_regime = None. 소비자(`read_regime`)는 이미 None을 "모름"으로 처리한다 |

판정 불가일은 통계에서 통과·탈락이 아니라 **별도 칸**으로 센다.

### 4.6 상태 파일(다음 조각 참고용 제안)

## 5. 평가

### 5.1 하네스

- 모집단: db-data `ohlcv_top100.csv`의 현재 100종목을 야후(수정종가)에서 2022-06~2026-09-29로 받았다. 2025-09-19 결측 행은 제거했다.
- 전방수익: **t일 종가 판정 → t+1 종가부터 h일**(판정 다음 날 진입). EW = top100 균등지수, KOSPI = ^KS11.
- NW-t: "해당 국면 더미 → 다음 20일 EW 수익" 회귀의 Newey-West t(lag 20)다. 국면 지표가 지수 수준이라 **하루 = 1관측**이고, 이는 일별 클러스터와 같다. 겹치는 20일 창의 자기상관은 NW로 보정했다.
- 사후 정답(평가 전용, 룩어헤드): t−10..t+10 중심 21일 균등지수 수익률의 IS 분위(10/30/70/90)로 5단계를 나누고, 중심 21일 변동성이 IS 중앙값을 넘으면 강한 쪽으로 본다. "그 시점 시장이 실제로 어땠나"와 얼마나 일치하는지 재는 기술(記述) 정확도다.
- 문턱은 모두 IS(2023-06-01~2025-06-30)에서 정해 동결했고, OOS는 2025-07-01~2026-09-29다.

## 7. 한계와 미해결

1. **예측력 없음(가장 중요).** 6단계 모두 다음 5·20일 수익 단조성을 만족하지 못했다(현행도 마찬가지다). 극단 국면의 다음 수익은 장세에 따라 부호가 뒤집힌다. 심 게이팅은 "이 상태에서 이 전략이 과거에 잘 됐나"를 국면별 성과로 따로 검증해야 한다. 이 라벨이 곧 매수·매도 신호는 아니다. 특히 매우하락에서 인버스(심6)를 켜는 것은 IS 자료상 손실 쪽이다(매우하락 뒤 20일 EW +7.7%).
2. **긴 추세 창을 쓸 수 없다.** Faber(10개월)·TSMOM(12개월)은 검증이 두터운 시간척도인데 운영 CSV가 100행이다. 보관을 250행 이상으로 늘리는 것은 별도 결정이 필요하다(범위 밖).
3. **코스피 지수 입력 없음.** 균등지수로 대리했다. 시총가중 코스피와는 삼성전자·SK하이닉스 비중 때문에 괴리가 있다(OOS 매우하락에서 EW −1.1% vs KOSPI −6.9%).
4. **변동성 문턱은 절대값이다.** 2026년은 vol10이 대부분 0.98을 넘어 횡보가 거의 강한횡보로 간다. 시장 변동성 수준이 구조적으로 바뀌면 재보정이 필요하다(연 1회 IS 중앙값 재산정 권장). 2026-09의 마지막 주(09-21~)는 vol10이 0.74~0.87로 내려가 약한횡보로 바뀌었다.
5. **생존편향:** 현재 top100 구성을 3년에 적용했다. 275종목 모집단과 3단계 79% 일치다.
6. **장중 평가는 근사다:** regime_observations에 종목별 가격이 없어 평행이동 가정을 썼다. 운영 반영 후 1~2주 실측으로 다시 재야 한다.
7. **범위 밖 발견:** 과제 설명의 "momentum = 평균 등락률"과 달리 운영은 **중앙값**이다(`_breadth_momentum`). 리베로 trend(`_adx`)는 ADX가 아니라 Kaufman 효율비다. 둘 다 이름과 실체가 다르므로 다음 조각에서 필드명·주석을 맞출 때 참고하라.
